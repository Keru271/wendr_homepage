Model Context Protocol (MCP) Integration Guide

Target Clients: Claude Desktop • Antigravity • Cursor • Standard: Open MCP v1.0 • Category: AI Tooling & Agent Infrastructure

01 // What is Model Context Protocol (MCP)?

Model Context Protocol (MCP) is an open-standard communication layer that enables AI models and autonomous coding agents to securely access external tools, live data sources, and contextual runtimes.

Instead of developing custom integrations for every AI client (e.g. separate plugins for Claude, Cursor, Antigravity, Zed, and VS Code), MCP solves the N × M fragmentation problem: developers build an MCP server once, and any MCP-compliant AI client can immediately query and execute its tools.

The 3 Core Primitives of MCP

🛠️ 1. Tools

Executable functions that the AI model can invoke with structured parameters (e.g. running SQL queries, creating GitHub Pull Requests, invoking REST APIs, executing Docker commands).

📦 2. Resources

Contextual data providers that the user or agent can attach (e.g. reading database schemas, live log streams, OpenAPI definitions, or memory graph snapshots).

💬 3. Prompts

Standardized, parameterized prompt templates and guided workflow runbooks provided directly by the server to guide the AI assistant.

03 // How to Configure MCP in Claude, Antigravity & Cursor

Select your environment below to view configuration file paths, JSON schemas, transport protocols, and step-by-step setup instructions.

Claude Desktop Configuration

Claude Desktop communicates with MCP servers over standard input/output (stdio). Configuration is stored in a central JSON file:

  • Windows: %APPDATA%\Claude\claude_desktop_config.json (e.g. C:\Users\<Username>\AppData\Roaming\Claude\claude_desktop_config.json)
  • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Linux: ~/.config/Claude/claude_desktop_config.json
claude_desktop_config.json JSON Configuration 
{
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-postgres",
        "postgresql://postgres:password@localhost:5432/omnistore_cms"
      ]
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "ghp_yourPersonalAccessToken"
      }
    }
  }
}

Using MCP in Claude:

  1. Save the configuration file and completely restart Claude Desktop.
  2. Look for the Hammer (🔨) icon at the bottom right of the message box.
  3. Click the icon to see all connected tools and their status. Claude will automatically invoke tools during conversations.

Google Antigravity IDE Configuration

Antigravity supports both local Stdio (command/script) and remote SSE (Server-Sent Events) transports. MCP servers can be configured globally or bundled into workspace plugins.

  • Global Scope (All Sessions): ~/.gemini/config/mcp_config.json
  • Plugin Scope: plugins/<plugin_name>/mcp_config.json
  • Workspace Discovery: Automatically read from .agents/ or plugin manifests.
~/.gemini/config/mcp_config.json Antigravity Schema 
{
  "mcpServers": {
    "sqlite-helper": {
      "command": "sqlite-mcp-server",
      "args": ["c:/Users/Nikhil/Desktop/cms/data.db"],
      "env": {
        "DB_READONLY": "true"
      }
    },
    "remote-team-service": {
      "serverUrl": "https://mcp.internal.company.com/sse"
    }
  }
}

How Antigravity Agent Uses MCP:

  1. Tool Discovery: Antigravity connects to configured servers upon session startup, registering tools as either eager or lazy tools.
  2. Lazy Loading: Tools are seamlessly called via call_mcp_tool to conserve prompt tokens until activated.
  3. Inspection UI: In the Antigravity IDE interface, navigate to Additional Options (...) > MCP Servers to monitor connected servers, view active schemas, and test connections.

Cursor AI Editor Configuration

Cursor natively integrates MCP into Cursor Composer (Agent Mode) and Cursor Chat.

Method 1: Via Cursor Settings UI (Recommended)

  1. Press Ctrl + Shift + J (Windows/Linux) or Cmd + Shift + J (macOS) to open Cursor Settings.
  2. Navigate to Features > MCP Servers.
  3. Click "+ Add New MCP Server".
  4. Enter Server details:
    • Name: postgres-db
    • Type: command (or sse)
    • Command: npx -y @modelcontextprotocol/server-postgres postgresql://user:pass@localhost:5432/mydb

Method 2: Project-Level Workspace Config (.cursor/mcp.json)

Create a .cursor/mcp.json file in your repository root to share MCP definitions with your team:

.cursor/mcp.json Project Scope 
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "C:\\Users\\Nikhil\\Desktop\\cms"
      ]
    }
  }
}

Using MCP in Cursor Composer:

Switch Composer mode to Agent. When prompted to inspect external databases, git repositories, or run external CLI tasks, Cursor will automatically invoke the corresponding MCP tool.

05 // Security Guidelines & Best Practices

🔒 Least Privilege Access

For database MCP servers, always connect using read-only database credentials where possible (e.g. DB_READONLY=true) to prevent accidental deletions.

🛡️ Protect Secret Tokens

Never commit raw API keys or personal access tokens into public .json repository files. Always reference environment variables or local user profiles.

⚡ Context Window Efficiency

Only enable MCP servers that are directly relevant to your current project. Adding dozens of servers injects heavy JSON schemas into prompts, which increases latency and token costs.

📁 Path Scoping

When running filesystem MCP servers, strictly restrict allowed directories to your current project folder to prevent unauthorized directory traversal.
