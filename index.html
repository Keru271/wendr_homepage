QUESTIONS & ANSWERS

FREQUENTLY ASKED QUESTIONS

Everything you need to know about the multi-tenant architecture, Developer API, and deployment options.

How does multi-tenant store isolation work? +
Every merchant store is partitioned at the database layer with tenant-specific identifiers and schema filters. Fastify request handlers resolve store tenancy via custom domain, subdomain slug, or explicit header keys (x-store-id) ensuring 100% data boundary security.
What is the difference between CMS (Port 5000) and Developer API (Port 5002)? +
The CMS backend on port 5000 governs administrative merchant operations (inventory management, financial reconciliation, theme configurations, user accounts). The Developer API on port 5002 exposes a high-performance public RESTful API specifically designed for headless storefronts, mobile apps, and point-of-sale integrations.
Can I customize the Visual Mega Menus from the CMS? +
Yes! The CMS Navigation Studio gives you direct privileges to configure 2-column feature cards (All Products, Featured Drops, Special Offers), custom section titles, "View All" destination URLs, promo card banner images, and footer highlight badges with live interactive previews.
How do I self-host OmniStore CMS on my own cloud? +
OmniStore CMS runs on standard Node.js (v18+) and PostgreSQL environments. You can run all microservices with Docker Compose, deploy to AWS/DigitalOcean/GCP, or run locally using our fastify and next dev servers.
